# 十一本书共识矩阵（方法论基础，背景资料）

## 共识（所有书都认同，必须遵守）

1. **吃真食物、原食物**，减少加工食品与精制糖（《疗愈的饮食与断食》《吃土》《谷物大脑》《吃肥见瘦》《超越百岁》）。
2. **优质脂肪无害且必要**，坏脂肪（反式脂肪、精炼种子油过量）有害（《吃肥见瘦》《疗愈的饮食与断食》）。
3. **稳定血糖与胰岛素**是健康的基石（《超越百岁》《谷物大脑》《吃肥见瘦》）。
4. **肠道健康 = 免疫健康**（《吃土》《免疫功能90天复原方案》）。
5. **减少麸质与精制碳水**，降低炎症（《谷物大脑》《抗炎》《桥本甲状腺90天治疗方案》）。
6. **断食是工具**，非目的，须配合时机与个体状态（《周期断食》《疗愈的饮食与断食》《超越百岁》）。
7. **肌肉量是长寿的保险**，蛋白质要足但不过量（《超越百岁》）。

## 各书专属工具（何时作为背景资料介绍）

> **本表仅供解释各书观点，不直接触发饮食治疗方案；任何疾病、症状或用药场景一律先经过安全路由（safety-rules.md），不自动调用下表方案。**

| 书 | 核心观点（背景资料） | 何时作为背景资料介绍 |
|---|---|---|
| 《周期断食》(Mindy Pelz) | 禁食循环：能量期（1-10天/16-19天）酮生物+按 L0/L1 安排禁食；排卵期禁食≤15h；经前一周不禁食+平衡激素饮食 | 女性用户 |
| 《疗愈的饮食与断食》(杨定一) | 断糖三阶段（糖+淀粉<50g/天）+ 2MAD/OMAD + 先脂肪蛋白蔬菜后淀粉 | 所有人（默认） |
| 《吃出自愈力》(William Li) | 5 大防御系统 × 每天≥5 种防御食物 × 5 个进食机会（5×5×5）；26 种 Grand Slammers | 所有人（默认） |
| 《抗炎》(Maggie Berghoff) | 炎症类型自测 + 三步程序 + Triple Trouble 三必去（乳制品/糖/谷物） | 用户主动了解抗炎饮食时介绍 |
| 《谷物大脑》(Perlmutter) | 无麸质 + 3/4 盘蔬菜 + 蛋白配菜 + 每年4次72h清水断食（原书观点，属 L2 医疗监督范围） | 用户主动了解时介绍 |
| 《吃肥见瘦》(Mark Hyman) | 21 天重置 + Pegan 饮食（非淀粉蔬菜50-70%、好脂肪充足、豆类≤1杯/天） | 减重用户主动了解时介绍 |
| 《吃土》(Josh Axe) | 五步协议（Remove/Reseed/Restore/Release/Reseal）+ 3天骨汤断食 + 土壤益生菌 | 用户主动了解肠道话题时介绍 |
| 《免疫功能90天复原方案》(Susan Blum) | 4 步：以食为药→减压→修复肠道→支持肝脏 | 用户主动了解时介绍（不自动执行） |
| 《桥本甲状腺90天治疗方案》(Izabella Wentz) | 90天三阶梯：肝支持→肾上腺→肠道；三阶梯饮食；禁断食 | 桥本用户主动了解时介绍（不自动执行） |
| 《超越百岁》(Peter Attia) | 营养3.0（CR/DR/TR）+ 代谢目标数字（血糖≤100、TG:HDL<2:1等） | 40+ 岁用户主动了解长寿话题时介绍 |

**跨书蛋白质观点**（仅作观点介绍，不自动执行）：Attia/Hyman 主张高蛋白（1.6 至 2.2 g/kg）；杨定一主张低蛋白（20 至 30g/日）——用户问到时如实介绍两种观点，**默认以安全下限计算**。
