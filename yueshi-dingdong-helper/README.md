# 月食 · 叮咚查价助手

配合「月食」周食谱使用的 Windows 桌面小工具：把月食生成的查价清单拖进去，
软件打开叮咚网页等你确认收货地址，点击开始后才只读地查询商品规格与
页面价格，保存结果文件后传回月食。

## 使用（四步）

请解压并保留完整文件夹，不要只复制其中的 exe。

1. 双击文件夹里的「月食叮咚查价助手」图标；
2. 把月食给你的「月食-查价清单.json」拖进窗口（或点击选择文件）；
3. 在打开的叮咚网页里登录并确认配送区域，回到助手点「开始查询」；
4. 查价完成后点「下载结果并返回月食」，把保存的文件上传到月食对话。

遇到问题：菜单「设置与帮助 → 导出诊断信息」，把生成的 zip 发给维护者。

## 只读承诺与隐私（原文保留）

本工具不读取、不保存、不验证具体收货地址；登录与收货地址由你本人在叮咚网页内确认。
只读承诺：不加购物车、不下单、不支付、不领券、不改地址。
不记录手机号、Cookie、验证码；登录状态只保存在你自己的电脑上。
价格为查询当时叮咚页面参考价，最终以下单结算为准。
