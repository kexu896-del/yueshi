# ADR-0003：跨仓探针策略（行为对拍优先、助手缺席降级）（round75）

- 状态：已接受
- 日期：2026-09-21

## 背景

技能仓有三个测试对独立仓库「叮咚查价助手」做探针，历史上：

- 每个测试各自拼 `../yueshi-dingdong-helper/...` 路径并维护"平铺/嵌套"两种布局（四次重复实现）；
- 助手源码缺失时不做降级，直接 `FileNotFoundError` 崩溃——只分发技能包时整包出现 3 个假失败（Kimi 提取副本 69/72 即此原因）；
- 探针以"读对方源码文本"为主（词表存在、版本常量字符串、诊断字段名），测不出真实行为漂移（round73 的「全麦味」守卫缺失即例证）。

## 决策

1. **统一探针模块**：`tests/probe_common.py`——`helper_src_dir(skill_root=None)`（平铺/嵌套两种布局，缺失返回 None）、`read_helper(rel)`、`load_helper_module(name, rel)`、`skip(reason)`；四个跨仓测试统一使用，路径探测只此一处。
2. **探针分层（写测试前先声明其层级）**：
   - **同步类**（词表/版本/判定与形态行为）：必须是**行为对拍**——同一 golden 样本在技能侧与助手侧执行并断言一致（tests/test_round73），外加快照新鲜度校验（重导出逐字节比对）。
   - **功能契约类**（助手诊断字段 `run-summary.json`、概念关系键 `parent_category_query` 等）：允许**文本契约探针**——验证接线存在；运行真实助手需要 Playwright 与登录态，不适合放进常规回归。
   - **结构守卫类**（判定器不得按品类硬编码分支）：允许**源码扫描**——守护的是代码形状而非运行行为。
3. **缺席降级**：助手源码/快照不在位 → 打印 `SKIP: ...` 并 exit 0；在位 → 保持硬断言，不得静默跳过。
4. **策略自测**：`tests/test_round75_cross_repo_probe_policy.py` 验证双布局解析、统一接线、无助手副本时 67/69 的 SKIP 行为、以及助手在位时"无 SKIP 的硬校验"。

## 后果

- 技能包单独分发/回归：跨仓探针输出 SKIP，不再出现假失败；两仓并列时探针强度不变。
- 同步类漂移只能通过行为对拍暴露——新增同步校验必须写进 test_round73 式对拍，不能靠文本探针。
- SKIP 的残余风险（助手缺席时漂移不可见）由发布链兜底：助手构建前强制重导出快照（`build_exe.py`），助手侧 dev 回归（导出契约/规则矩阵）必须通过。
- 新增跨仓探针不再复制路径代码；换目录布局只改 probe_common 一处。
