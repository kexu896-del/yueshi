# 月食（yueshi）——采购驱动的周期断食周饮食计划技能

> 适用 SKILL 版本：1.4.3

## 这是什么
根据身体周期、采购渠道、当地价格和做饭条件，生成真正**买得到、做得完、吃得完**的一周饮食方案：
先定食材篮子（买什么），再从结构化菜谱库选菜（怎么做），最后反向汇总采购清单（怎么买）。
输出：7 天菜单 + 采购清单（食材、购买量、常见规格、参考价、平替、剩余去向）+ 营养校验；最终格式按用户单选（PDF/网页/Markdown/Word）。

## 使用前需要提供的信息
不需要逐项填写，按平常说话的方式描述即可；缺少的信息，月食会合并成一轮询问。

- **关键八项**：
  1. **基本情况**：人数、年龄、身高、体重、健康目标等；
  2. **避开事项**：过敏、医嘱、宗教要求和明确不吃；
  3. **周期情况**：适用时提供周期日期、规律性和断食经验，由月食据此推算本周安排；
  4. **吃饭做饭**：需要安排的餐次、外食、厨具和可用时间；
  5. **菜系口味**：偏好菜系、味型和辣度；
  6. **预算库存**：本周预算类型、预算金额和已有库存；
  7. **做法选择**：是否接受一锅餐、提前备餐、剩余复用和免开火组合；
  8. **输出格式**：PDF、网页、Markdown 或 Word 单选。

## 使用过程
- **描述实际情况**：告诉月食人数、餐次、口味、预算、做饭条件和需要避开的食物。缺少的信息会合并询问。
- **删除不想要的食材**：月食给出本周候选，你只需要回复不想要的编号；都可以就回复"都可以"。
- **月食生成菜单并检查营养**：这一阶段通常不需要额外操作。
- **选择叮咚时，完成一次查价**：使用查价助手读取清单，完成后把价格结果上传回对话。
- **获取最终计划**：包括 7 天菜单、做法、采购清单、预算和剩余食材安排。

## 本周采购价格方式
每次制定新计划时选择一次：

**A. 使用叮咚查价助手**

- 按当前页面商品、包装和价格规划采购；
- 菜单和采购需求确定后，月食会生成一份查价清单；
- 完成查价并上传结果后，再生成最终文件。

**B. 使用公开参考价格**

- 不使用查价助手；
- 按所在地公开价格或同类商品价格估算；
- 菜单和营养完成后可直接生成最终文件。

> 如果本周还没有选择，月食会在食材预选时一并询问，不会自行默认。

## 使用叮咚查价时
只有在本次计划的食材预选环节明确选择「叮咚查价助手」，月食才会进入查价链路。
月食先完成菜单、营养和最终新购需求，再交付唯一正式的「月食-查价清单.json」。此时流程暂停，不会提前生成最终文件。

使用本机「月食叮咚查价助手」完成查价后，请上传「月食-叮咚价格结果.json」。月食校验结果、更新包装和预算后，再一次性生成最终文件。

### 叮咚查价助手使用说明
- **准备助手**：解压并保留完整文件夹，不要只复制其中的 exe。
- **运行前提**：Windows 本机装有 Chrome 或 Edge 浏览器（或使用助手内置浏览器）。
- **四步操作**：① 把「月食-查价清单.json」拖进助手窗口 → ② 在打开的叮咚网页中登录并自行确认收货地址 → ③ 点击"开始查询"等待完成 → ④ 点击"下载结果"，把「月食-叮咚价格结果.json」上传回月食对话。
- **只读承诺**：助手只读取页面商品与价格，**不加购、不下单、不支付、不领券、不改地址**，不读取也不保存你的具体收货地址。
- **价格口径**：结果为查询时点的页面参考价，实际以叮咚结算页为准。

## 各格式差异
「对应菜单及用量」模块按格式差异化展示：
- HTML：完整保留，支持折叠。
- Word：完整保留，置于附录。
- Markdown：完整保留，按食材分组。
- PDF：为保持紧凑，不展示该模块（固定规则，非用户选项）。

## 安全声明
输出为一般性饮食建议，不构成医疗建议；孕产哺乳、未成年、慢病用药者请先咨询医生。
