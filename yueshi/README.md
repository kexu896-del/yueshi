# 月食（yueshi）——采购驱动的一周饮食计划技能

> 适用版本：`yueshi-1.4.3`
>
> 可用于任何支持 `SKILL.md` / Agent Skills 的 AI 工具（Claude Code、opencode、Kimi Code CLI、Codex 等）；也可以把 `yueshi/` 打包成 zip 直接作为对话附件。

## 这是什么

不是先写菜单再想怎么买，而是**先定这周买什么，再决定做什么菜**：

- 按人数、周期阶段、健康目标、口味、预算和做饭条件，生成 7 天菜单；
- 菜单来自结构化菜谱库，不是凭空编的菜名；
- 反向汇总成一份能照着买的采购清单：食材、用量、常见包装、参考价、平替、剩余去向；
- 全程做营养校验，最后按你选的格式输出。

输出：**7 天菜单 + 采购清单 + 营养校验**；格式为 PDF / 网页 / Markdown / Word 单选。

## 适合谁

- 想减重、控糖或调整体成分，但不想每天算热量；
- 一个人吃，希望买得少、不浪费、做得完；
- 两口之家或全家同餐，需要"同餐不同量"或安全分餐；
- 有周期阶段、断食经验或低碳水安排，需要把节奏排进一周；
- 想按叮咚实时页面价格做预算，而不是拍脑袋估价。

## 使用前需要提供的信息

不用逐项填表，按平时说话的方式描述即可；缺的信息会合并成一轮询问。

1. **基本情况**：人数、年龄、身高、体重、健康目标；
2. **避开事项**：过敏、医嘱、宗教要求、明确不吃的食物；
3. **周期情况**：适用时提供周期日期、规律性和断食经验，由月食推算本周安排；
4. **吃饭做饭**：要安排几餐、是否外食、厨具和可用的做饭时间；
5. **菜系口味**：偏好菜系、味型、辣度；
6. **预算库存**：预算类型与金额、家里已有的食材；
7. **做法选择**：是否接受一锅餐、提前备餐、剩余复用、免开火组合；
8. **输出格式**：PDF、网页、Markdown、Word 单选。

## 使用过程

1. **描述实际情况**：人数、餐次、口味、预算、做饭条件和要避开的食物；
2. **删除不想要的食材**：月食给出本周候选，只回复不要的编号；都可以就回"都可以"；
3. **月食排菜单并校验营养**：这一阶段通常不需要你操作；
4. **选了叮咚查价就查一次价**：用助手读取清单，把价格结果上传回对话；
5. **拿最终计划**：7 天菜单、做法、采购清单、预算和剩余食材安排。

## 家庭模式

出现"双人餐""两人吃饭""全家食谱""同餐不同量""多人共餐""家庭版"等说法时，自动切到家庭流程：

- 一次检索、一次装配，按成员分配份量；
- 同餐同量 / 同餐不同量 / 安全分餐三种处理；
- 批量营养校验，最多两轮全局微调；成员缺席只合并局部修改。

## 体质食养（可选，不诊断）

只有你**明确自述**时才会启用（例如"我怕冷、手脚凉""容易上火"，或直接说体质名）：

- 参考《中医营养学》《中医食疗学》等教材的性味与体质食养清单，覆盖 11 种体质（九种标准 + 血虚 + 阳盛）；
- 只做**食材与菜谱的软偏置**：不改变候选范围、餐次、营养目标、预算和安全约束；
- 描述矛盾（如"又怕冷又怕热"）或无法识别时，不启用，也不会猜；
- 不输出体质判定、辨证、疗效或剂量建议；特禀体质只走安全提示。

## 本周采购价格方式

每次制定新计划时选一次：

**A. 使用叮咚查价助手**

- 按当前页面商品、包装和价格规划采购；
- 菜单和采购需求确定后，月食生成一份「月食-查价清单.json」，流程暂停；
- 查价完成并上传结果后，再生成最终文件。

**B. 使用公开参考价格**

- 不调用助手；
- 按所在地公开价格或同类商品估算；
- 菜单和营养完成后直接生成最终文件。

> 没有选择时，月食会在食材预选环节一并询问，不会自行默认。

## 使用叮咚查价时

只有本次计划明确选择「叮咚查价助手」，才会进入查价链路。月食先完成菜单、营养和最终新购需求，交付唯一正式的查价清单，然后暂停，不提前生成最终文件。

使用本机「月食叮咚查价助手」完成查价后，上传「月食-叮咚价格结果.json」。月食校验结果、更新包装和预算，再一次性生成最终文件。

### 助手使用说明

- **准备**：解压并保留完整文件夹，不要只复制其中的 exe；
- **前提**：Windows 本机已安装 Chrome 或 Edge（助手调用系统浏览器，不再内置浏览器）；
- **四步**：① 把查价清单拖进助手 → ② 在打开的叮咚网页登录并自行确认收货地址 → ③ 点"开始查询" → ④ 点"下载结果"，把价格结果上传回对话；
- **只读承诺**：只读页面商品与价格，不加购、不下单、不支付、不领券、不改地址，不读取也不保存具体收货地址；
- **价格口径**：结果为查询时点的页面参考价，实际以叮咚结算页为准。

## 各格式差异

「对应菜单及用量」模块按格式差异化展示：

- **HTML**：完整保留，支持折叠；
- **Word**：完整保留，置于附录；
- **Markdown**：完整保留，按食材分组；
- **PDF**：为保持紧凑不展示该模块（固定规则，非用户选项）。

## 安全声明

输出为一般性饮食建议，不构成医疗建议；孕产哺乳、未成年、慢病或用药者请先咨询医生。
