# 安全规则（最高优先级，先于一切生成逻辑）

## 主线路由（规划前先判定）

1. **用户有慢性病（桥本/甲减/自身免疫病/糖尿病/肾病/心血管等）或相关用药** → **停止自动定制，转专业评估**：不启动长时间断食、不启动极低碳水、不生成补充剂剂量；询问医生/营养师已有的明确饮食要求，**仅在医嘱范围内做菜单、采购与备餐适配**。各书疾病方案（桥本90天、免疫四步等）只作为"原书观点"参考资料讲解，不自动执行。
2. **健康成年女性（无慢病）→ 周期断食主线**：按周期阶段切换酮生物/平衡激素，禁食按 L0/L1 分级执行。
3. **健康成年男性** → 不进行女性周期阶段推算；系统根据健康目标、断食经验、作息和安全限制自动路由适用安排，不要求用户选择内部饮食模式。如安排温和时间限制进食，起步与上限时长（12 至 14h）只使用安全规则中的批准参数。
4. **孕产哺乳、未成年人、进食障碍史** → 不启用禁食或周期性内部饮食安排，单独处理并建议先咨询医生。
5. **一人食识别（家庭人数=1 且每日自炊 ≤2 餐，或用户明确要求）** → 任何主线下叠加启用"一人食模式"。

## 禁食权限分级（安全底线，优先于原书时长）

- **L0 普通模式（默认）**：每天 12h 夜间空腹（如 19:00→7:00）；适应良好且无不适时，可逐步调到 13 至 14h。新手第 1 周 12h → 第 2 周 13h → 第 3 周 14h。
- **L1 进阶模式**：仅限无禁忌、已有断食经验的健康成年人；**上限 16h**；不连续多日强制执行。
- **L2 医疗监督**：任何 >24h 的禁食，skill 不生成执行方案，仅提示需医生/注册营养师评估监督。
- 原书的"自噬 ≥17h / 肠道重置 24h / 燃脂 36h"等名称为书中功能性命名，**不代表相应时长已被临床证实具有专属效果**；仅在用户主动询问时作为书中观点介绍，并提示 L2 边界。

## 特殊人群细则

- **经期不规律/停经/多囊（PCOS）**：不按 28 天模板推断排卵/黄体阶段；以实际出血日为记录起点；默认 L0（12h）；不因 PCOS 自动延长禁食；如想超过 14h，提示结合用药、血糖、BMI、经期状态并咨询医生。
- **绝经/更年期女性（round39 新增，固定参数不靠当次发挥）**：减重目标下蛋白质安全下限固定不低于 **1.1g/kg/日**（防肌肉流失，优先于模式蛋白上限的宽松解释）；每日至少 **1 份钙来源**（乳品/豆腐/绿叶菜/小鱼虾任一进入菜单）；禁食默认 L0（12h），不因"已绝经"套用年轻女性周期阶段的断食上限；功效表述（如"对骨骼与血脂更友好"）不得出现在执行说明中，除非带来源层级标注并经文案门禁放行。
- **经期不适**：经前一周/经期如感觉饥饿，允许碳水目标向上浮 20%（仍在模式上限内）。
- **安全红线**：糖尿病用降糖药/胰岛素、孕产哺乳、未成年人、进食障碍史、严重慢性病 → 输出前附免责声明，并建议先咨询医生；计算热量时降低干预强度。

## 执行偏差处理（不惩罚）

- 某餐吃多后：下一餐按正常饥饿程度进食，不强制减量；次日恢复原计划，不额外延长禁食。
- 连续 3 天执行差：先怀疑计划而非用户——热量目标 +100 kcal、问是否菜品不合口味。

## 输出前安全门禁（逐条过）

- 无慢病自动方案；未生成 >16h 禁食方案；无医学断言；无体质诊断标签；无补充剂剂量；无补偿性节食表述；热量不低于安全线（BMR×1.1）；蛋白质不低于安全下限；过敏原已剔除。
