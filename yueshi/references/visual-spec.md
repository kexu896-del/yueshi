# 视觉与输出规范（网页/Markdown/PDF 通用）

> 本节规则为**硬性约束**，网页版以 `templates/plan-template.html` 为权威骨架（奶油纸白+薰衣草紫/鼠尾草绿的编辑式长页，样式与结构以模板文件为准）。

## 写作约定（所有格式通用）

- 标题只写"饮食计划 · 日期区间"；文件名 `饮食计划_08-18 至 08-24`（只写日期区间，不写"第X周"），存 `diet-plans/` 下。
- **结构顺序：本周档案 → 采购清单（前置）→ 每日安排 → 营养素校验 → 备餐建议 → 执行提示。**
- 档案表不铺陈大段分级体系，只写本次结论。
- 每日安排表必须逐日标注**进食窗口+禁食窗口**（如"进食 7:00-19:00；禁食 19:00→7:00 · 12h"），阶段/模式两段标注，阶段标签带生理周期说明（如"能量期 · 第8-10天"）。
- **备餐体现在每日表里**：周日加"备餐日"行，周三加"解冻日"行。
- **HTML 表格防断列**：每日安排表不使用 rowspan——阶段/窗口信息写进每天一条的"日条"分隔行（`<tr class="daybar"><td colspan="7">…</td></tr>`），明细行全为普通单元格；合计行用 `.day-total` 深色带。
- **理论依据（必附，只说人话，不列书目章节，不写成医学因果断言）**：每条关键规则用一两句话讲清本计划采用的方法与理由；用户异议时先讲方法与理由，书中没涉及的明说"此为通用营养学建议"；医嘱优先。直接展示，不使用折叠。
- **用大白话解释"为什么这样吃"**（档案后一小节，两三点）：模式切换原因（面向用户用"能量期/排卵期/经前一周"等通俗名）；五运六气影响（仅启用该模块时写）；食养偏好（如"偏好温热熟食"，不得输出体质判断标签）。
- **食谱禁忌**：计划正文不出现排泄/便溺类描述、不出现体质诊断标签。
- **每日建议逐日独立**：每天的当日建议按当天菜单、周期阶段与前后日衔接单独撰写；逐日雷同（如把周一建议复制到全周）视为验收失败。
- **就餐安排按用户明确信息渲染**：每日安排表按用户提供的逐日做饭安排；周末未说明时标"待确认"，不自行假设三餐在家，也不把仅适用于工作日的地点（如单位食堂）复制到周末；七天相同就餐模式本身不是错误，与用户明确信息冲突才是。
- **营养素校验表是内部步骤，不写进用户计划**：达标就整节删去，只在有超标项时展示提示行。
- **饮品（默认不强调轮换）**：禁食期首选水；黑咖啡/无糖茶按用户情况适量；防弹咖啡仅作可选项、按脂肪余量计入。
- **备餐与冷冻**：上班族周日下午批量做 2-3 道耐冷冻菜分装冷冻，周三晚解冻；周中晚餐 ≤15 分钟。
- **运动**：仅启用功法模块时单列一节；否则一句"保持日常活动量"。
- **营养信息（不设独立章节）**：默认不生成"营养概览"章节，不生成环形图、柱状图、进度条或目标带。每日菜单末尾只保留一行当日估算（净碳水、蛋白质、脂肪、总能量）；外食日标区间并注明"不标记为精确达标"。全部达标时不展示周汇总；超标/低于安全线/偏离原书参考值/外食低置信度时，在"执行提示"中提醒。用户主动要求时可另附七天汇总表或 CSV。
- **周期时间轴**：保留（切换日加分隔线），与月相轨道视觉分开。
- **阶段不只靠颜色**：颜色+文字+图形（能量期紫点、排卵期绿点、经前期杏色），保证黑白打印可辨。

## 月食品牌视觉（默认开启）

- 月相是"月食"固定品牌元素：Hero 底部月相轨道（7 天月相连线成轨，当前日期月亮放大 6%），配一行由实际七天阶段生成的文案（当周无满月不得写满月）。
- **月相只用于日期视觉记录，不参与周期、饮食或健康判断**；页面明确标注月相轨道与身体周期轨道无因果映射。
- 打印节墨模式隐藏月相填充，仅保留轮廓。

### 月相轨道渲染算法（连续相位，不用离散模板）

- 每天计算：`age`（月龄 0 至 1）→ `angle = 2π×age`、`illumination = (1−cos(angle))/2`、`terminator = cos(angle)`、`waxing = age<0.5`。
- **动态 SVG Path**：暗底圆 + 亮面路径 `M top A r r 0 0 outerSweep bottom A rx r 0 0 innerSweep top Z`，其中 `rx = |terminator|×r` 随相位连续变化；`illumination<0.015` 画新月（暗圆+淡金轮廓）；`>0.985` 画满月（完整亮面）。
- 亮面 `#fff8df`、暗面 `#2f2b23`、轮廓 `rgba(255,248,223,.36)`；**盈月右侧亮、亏月左侧亮**。
- 校验点：phase=0.125 右侧细月牙 / 0.25 右半亮 / 0.375 左少量暗 / 0.75 左半亮。
- **禁止轨道线穿过月面**：轨道线置于月亮下层（`isolation:isolate` + `z-index`）或只留月亮下方短刻度；月面 svg 背景=hero 底色。
- 尺寸 `width:clamp(68px,7vw,92px)`；今天只放大 6%（scale 1.06）。失败回退：计算失败只显示文字名称。

## 配色与版式（柔和暖调，编辑式长页）

- 奶油纸白 `#faf8f0` 底、暖褐 `#5a564a` 字、浅灰绿边 `#e5e2d4`、柔和薰衣草紫 `#a08ac9` + 鼠尾草绿 `#7fa283` 点缀；hero 深色块。
- **深色大背景仅允许 Hero**；正文整段背景只用纸白/浅杏/浅绿（鼠尾草）/浅薰衣草/淡茶褐——备餐区浅鼠尾草绿、采购浅杏、理论依据浅薰衣草。
- **少卡片多版面**：整段背景切换制造章节感；每章只强调一个主信息（章节编号+一句话大标题+大数字）；不对称 12 列网格、超大日期、圆角减量。
- **章节编号（.secnum）**：`h2.sec` 设 `display:grid; grid-template-columns:72px minmax(0,1fr); column-gap:14px; align-items:end`；`.secnum` 为 `position:static; color:var(--purple-text); opacity:.48; font-size:64px; line-height:.78; font-family:"Noto Serif SC","Songti SC",Georgia,serif`（必须显式写衬线中文字体栈，禁止只写 Georgia）；移动端缩为 48px 列宽/38px 字号；所有章节必须带 secnum span，编号不得与任何背景同色。
- **左侧章节目录（桌面端）**：宽 200 至 220px，"月食/本周计划"品牌块；两位编号+文字；当前章节浅薰衣草底+深紫字+粗体，用 IntersectionObserver 更新 active 并加 aria-current="location"；初始默认激活"今天吃什么"。
- **章节编号完整性**：所有核心章节输出两位编号（01 今天吃什么 / 02 本周阶段 / 03 采购清单 / 04 备餐任务 / 05 七天菜单 / 06 为什么这样吃 / 07 执行提示）——**"本周食材选择"章节已从正式文件取消**，预选过程只保留在内部（initial_basket/removed_items/replacements/locked_basket 不进用户文件），结构 `<h2 class="sec"><span class="secnum">05</span>七天菜单</h2>`，生成后校验 01-07 齐全且与左侧目录一一对应。

## 网页信息架构（网页端与打印端分开设计）

- **网页顺序**：Hero 状态概览 → 今天吃什么 → 本周阶段 → 采购清单 → 备餐任务 → 七天菜单 → 为什么这样吃 → 执行提示与安全提示。
- **打印顺序**：本周档案 → 采购清单 → 备餐任务 → 七天菜单 → 执行提示 → 理论依据。
- **Hero 是状态型不是装饰型**：四个状态块（阶段/当前模式/今日空腹/本周饮食预算）；外食日显示"营养值为区间估算"；月相轨道在 Hero 底部。
- **今日卡片（必备）**：高亮+浅绿底+"今天"标签；含各餐、进食窗口、当晚解冻任务。
- **每日菜单展示（全部展开，不用宽表、不折叠）**：每天一张单列纵向大卡；每餐纵向结构：餐次与时间 → 菜名 → 食材与克数 → 营养素一整行 → 用时与置信度标签；所有容器 `min-width:0`，食材与营养文本允许换行，320px 宽度完整显示、页面无横向滚动条。
- **三级免责**：Hero 下一行短提示 + 慢病用药时的警示卡 + 页尾完整声明。
- **响应式三档**：<768 单列、正文≥16px、点击区≥44px；768-1100 两列概览；>1100 左侧目录+正文 max 1120px。
- **无障碍**：正文对比度用深色文字版（紫 #6f5a96、绿 #4f7358）；数字用 `font-variant-numeric:tabular-nums`；支持 `prefers-reduced-motion`。

## 采购清单页面（最终版）

- **主采购清单四个分类纵向排列**：①蔬菜与菌菇 ②肉蛋水产与豆制品 ③谷物、薯类与水果 ④油脂、坚果与调味。
- **每个分类内部桌面两列、移动单列**：名称 +（重量或数量·储存方式）副行 + 价格右对齐；不显示采购编号、菜单日期或使用日标签；**不得把多个不同食材合并成一个采购项**。
- 价格为估算时注明"按用户所在城市常见零售区间估算"；每种食材单独一项、写明数量和单位。
- **"食材和对应菜单"按格式差异化展示（round56）**：HTML 为全页唯一折叠交互——主清单下方可点击控制条，默认收起，展开后三列：食材｜总需求量｜对应菜单及用量，完整列出无截断；PDF 固定不展示该模块（为保持紧凑与可读性）；Word 置于附录、Markdown 按食材分组。除该区外，七天菜单、每日营养、理论依据一律不折叠。
- 采购总览卡：N 种食材 / 预计 ¥X / 冷冻 N 份 / 周中补货 N 项 / 现买现吃 N 项。
- **采购清单逐项可勾选**：勾选状态网页端用浏览器本地存储，打印版仅作勾选框；只列在家做的餐次食材——食堂/外卖日不列入采购。

## 预算方式与预算状态卡

- 允许"不设预算"；采集：金额、覆盖人数、是否包含食堂外卖、是否包含油米调味首购、弹性（严格/±5%/±10%/仅参考）。
- 自然月预算=**财务约束周期，按周执行**：月预算作总预算池，每周按当月剩余天数和剩余预算分配额度；**不因选月预算一次生成整月详细食谱**。
- 页面显示：月预算→本月预算/本周可用/本周预计/剩余金额；周预算→只显示本周预算；不设预算→Hero 显示"采购策略：优先性价比"，**不生成虚构的月预算**。
- 三类预算：基础库存＋每周生鲜＋机动余额；超预算修正顺序：**不得削减蛋白安全下限、基本能量线、蔬菜基本量、过敏原回避与医嘱要求**；无价格数据时输出"预算结构已生成，但缺少当地价格数据"，不伪造价格。

## 打印 CSS 与 PDF 门禁

- `@page`：A4 纵向，边距 12mm 11mm 13mm；隐藏导航、`section#today`、交互控件；hero 去深色背景。
- 章节标题：打印版 `h2.sec` 双列 grid（`16mm minmax(0,1fr)`），`.secnum` 改 `position:static; color:#6f5a96 !important; opacity:.62; font-size:34pt; print-color-adjust:exact`；标题与后续首个内容块不得分页。
- 七天菜单：日卡 `break-inside:avoid` 但压缩内边距（3mm 4mm）、餐次改 grid 三列、行距收紧，目标 A4 每页 2 天；禁止 day-card 强制另起一页。
- 采购清单：`shop-group` 允许跨页，`shop-item` 单项 `break-inside:avoid`。
- **PDF 紧凑度门禁（导出后逐页检查，任一失败即修）**：七天菜单连续一天一页；单张日卡不足页面 60% 却留大块空白；章节标题孤立页尾；同一天菜单重复打印；页面空白超 1/3。普通一周计划目标 6 至 10 页。


## 打印与 PDF 独立样式（styles/print.css，硬约束）

- 打印样式与网页样式分开维护（`styles/print.css` / `styles/screen.css`），PDF 生成用打印样式。
- **标题区域强制黑色**：`.plan-title, .plan-title h1, .plan-title .date-range, .plan-title .subtitle { color:#111111 !important; opacity:1 !important; text-shadow:none !important; -webkit-print-color-adjust:exact; print-color-adjust:exact; }`
- 标题文字层位于月相装饰之上：`.plan-title-content { position:relative; z-index:2; color:#111111 !important; }`；`.moon-decoration { position:absolute; z-index:0; opacity:0.28; }`
- 打印版月相：`@media print { .moon-decoration { fill:#B8861B; stroke:#795B12; opacity:0.38; } }`——避免白底浅黄月相覆盖文字。
- "饮食计划"、日期和副标题始终黑色；PDF 生成后检查标题、日期、分页、表格、中文字体和黑白打印。

## 午餐时间与状态分行渲染（修复"外食估12算:00"重叠，硬约束）

- 时间和外食状态是**两个独立字段**，分别渲染，禁止拼接为一段文本，禁止使用 absolute 定位叠放：

```html
<div class="meal-time">12:00</div>
<div class="meal-status">外食 · 区间估算</div>
```

- `.meal-time, .meal-status { position:static; display:block; }`
- `.meal-time { white-space:nowrap; min-width:4.8em; font-variant-numeric:tabular-nums; }`（时间不换行）
- `.meal-status { white-space:normal; overflow-wrap:anywhere; line-height:1.4; }`（状态可换行）
- 打印网格：`@media print { .daily-meal-grid { display:grid; grid-template-columns:4.8em minmax(0,1fr); column-gap:10px; } }`

## 文本清理（渲染前必做）

```python
import unicodedata
text = unicodedata.normalize("NFC", text)
text = text.replace("\u00ad", "")   # 软连字符
text = text.replace("\ufeff", "")   # BOM
text = text.replace("\u200b", "")   # 零宽空格
```

- 检查软连字符、BOM、零宽空格和异常全角冒号；检查午餐模板占位符是否被重复写入。
- HTML 屏幕和 PDF 打印分别测试（12:00 / 12:30 / 外食 / 自制 / 无午餐回归用例）。

## 采购清单与交互（硬约束）

- 采购清单一律**静态表格**，不设计可点击交互；网页不含 checkbox、localStorage 或勾选状态说明。
- 每次只生成用户单选的一种最终格式（pdf/html/md/docx）；中间文件写 tmp，不作为附件。

- **饮品（默认不强调轮换）**：禁食期首选水；黑咖啡/无糖茶按用户情况适量；防弹咖啡仅作可选项、按脂肪余量计入。
- **备餐与冷冻**：上班族周日下午批量做 2-3 道耐冷冻菜分装冷冻，周三晚解冻；周中晚餐 ≤15 分钟。
- **运动**：仅启用功法模块时单列一节；否则一句"保持日常活动量"。
- **营养信息（不设独立章节）**：默认不生成"营养概览"章节，不生成环形图、柱状图、进度条或目标带。每日菜单末尾只保留一行当日估算（净碳水、蛋白质、脂肪、总能量）；外食日标区间并注明"不标记为精确达标"。全部达标时不展示周汇总；超标/低于安全线/偏离原书参考值/外食低置信度时，在"执行提示"中提醒。用户主动要求时可另附七天汇总表或 CSV。
- **周期时间轴**：保留（切换日加分隔线），与月相轨道视觉分开。
- **阶段不只靠颜色**：颜色+文字+图形（能量期紫点、排卵期绿点、经前期杏色），保证黑白打印可辨。

## 月食品牌视觉（默认开启）

- 月相是"月食"固定品牌元素：Hero 底部月相轨道（7 天月相连线成轨，当前日期月亮放大 6%），配一行由实际七天阶段生成的文案（当周无满月不得写满月）。
- **月相只用于日期视觉记录，不参与周期、饮食或健康判断**；页面明确标注月相轨道与身体周期轨道无因果映射。
- 打印节墨模式隐藏月相填充，仅保留轮廓。

### 月相轨道渲染算法（连续相位，不用离散模板）

- 每天计算：`age`（月龄 0 至 1）→ `angle = 2π×age`、`illumination = (1−cos(angle))/2`、`terminator = cos(angle)`、`waxing = age<0.5`。
- **动态 SVG Path**：暗底圆 + 亮面路径 `M top A r r 0 0 outerSweep bottom A rx r 0 0 innerSweep top Z`，其中 `rx = |terminator|×r` 随相位连续变化；`illumination<0.015` 画新月（暗圆+淡金轮廓）；`>0.985` 画满月（完整亮面）。
- 亮面 `#fff8df`、暗面 `#2f2b23`、轮廓 `rgba(255,248,223,.36)`；**盈月右侧亮、亏月左侧亮**。
- 校验点：phase=0.125 右侧细月牙 / 0.25 右半亮 / 0.375 左少量暗 / 0.75 左半亮。
- **禁止轨道线穿过月面**：轨道线置于月亮下层（`isolation:isolate` + `z-index`）或只留月亮下方短刻度；月面 svg 背景=hero 底色。
- 尺寸 `width:clamp(68px,7vw,92px)`；今天只放大 6%（scale 1.06）。失败回退：计算失败只显示文字名称。

## 网页信息架构（网页端与打印端分开设计）

- **网页顺序**：Hero 状态概览 → 今天吃什么 → 本周阶段 → 采购清单 → 备餐任务 → 七天菜单 → 为什么这样吃 → 执行提示与安全提示。
- **打印顺序**：本周档案 → 采购清单 → 备餐任务 → 七天菜单 → 执行提示 → 理论依据。
- **Hero 是状态型不是装饰型**：四个状态块（阶段/当前模式/今日空腹/本周饮食预算）；外食日显示"营养值为区间估算"；月相轨道在 Hero 底部。
- **今日卡片（必备）**：高亮+浅绿底+"今天"标签；含各餐、进食窗口、当晚解冻任务。
- **每日菜单展示（全部展开，不用宽表、不折叠）**：每天一张单列纵向大卡；每餐纵向结构：餐次与时间 → 菜名 → 食材与克数 → 营养素一整行 → 用时与置信度标签；所有容器 `min-width:0`，食材与营养文本允许换行，320px 宽度完整显示、页面无横向滚动条。
- **三级免责**：Hero 下一行短提示 + 慢病用药时的警示卡 + 页尾完整声明。
- **响应式三档**：<768 单列、正文≥16px、点击区≥44px；768-1100 两列概览；>1100 左侧目录+正文 max 1120px。
- **无障碍**：正文对比度用深色文字版（紫 #6f5a96、绿 #4f7358）；数字用 `font-variant-numeric:tabular-nums`；支持 `prefers-reduced-motion`。

## 采购清单页面（最终版）

- **主采购清单四个分类纵向排列**：①蔬菜与菌菇 ②肉蛋水产与豆制品 ③谷物、薯类与水果 ④油脂、坚果与调味。

## 预算方式与预算状态卡

- 允许"不设预算"；采集：金额、覆盖人数、是否包含食堂外卖、是否包含油米调味首购、弹性（严格/±5%/±10%/仅参考）。
- 自然月预算=**财务约束周期，按周执行**：月预算作总预算池，每周按当月剩余天数和剩余预算分配额度；**不因选月预算一次生成整月详细食谱**。
- 页面显示：月预算→本月预算/本周可用/本周预计/剩余金额；周预算→只显示本周预算；不设预算→Hero 显示"采购策略：优先性价比"，**不生成虚构的月预算**。
- 三类预算：基础库存＋每周生鲜＋机动余额；超预算修正顺序：**不得削减蛋白安全下限、基本能量线、蔬菜基本量、过敏原回避与医嘱要求**；无价格数据时输出"预算结构已生成，但缺少当地价格数据"，不伪造价格。
