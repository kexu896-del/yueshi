# 中医食养风格参照（食谱修饰器，仅作食材风格参考，不作诊断）

> **定位：食谱修饰器。** 先生成营养与采购上可行的菜谱，再按本文件调整烹法/温度/味型；本文件**不进入生成链路**，不作筛选依据。
> **用户可见的只有五项**：当季食材 / 温度偏好（生冷或温热）/ 清淡或重口 / 汤羹或快炒 / 用餐时间。
> **不再进入流程的内容**：六经辨证、经方方剂、针灸、药材剂量、体质诊断标签、五脏疾病推断、由单一表现判断寒热虚实——一律不做。
> 从传统食养中只吸收生活化原则：五味不过偏、顺时令、多熟食、有汤羹、规律进食、少厚味。
> 仅供选食材与调味倾向时查询；**不输出体质判定结论**。

| 风格 | 特征（传统描述） | 饮食风格参考 |
|---|---|---|
| 平和 | 精力好、睡眠佳 | 均衡，随时令调 |
| 气虚 | 易疲劳、气短、易感冒 | 温补不腻：山药、鸡肉、小米；忌生冷过量 |
| 阳虚 | 怕冷、手脚凉 | 温阳：姜、羊肉、韭菜、桂圆；忌寒凉生冷 |
| 阴虚 | 口干、手足心热、失眠 | 滋阴：银耳、百合、梨、枸杞；忌辛燥 |
| 痰湿 | 体型偏胖、舌苔腻、头沉 | 化湿：薏米、冬瓜、陈皮、赤小豆；少油少甜 |
| 湿热 | 面油、口苦 | 清热利湿：绿豆、苦瓜、黄瓜、薏米 |
| 血瘀 | 面色暗、易瘀青、痛经 | 活血：山楂、黑木耳、洋葱、玫瑰花茶 |
| 气郁 | 易紧张、叹气、胸胁胀 | 疏肝：玫瑰花、陈皮、芹菜、柑橘类 |
| 特禀 | 过敏史 | 按过敏原回避 |

注：以上为传统食养观点，不作现代医学因果结论。
