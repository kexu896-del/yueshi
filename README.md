# yueshi
月食 yueshi —— 根据生理周期、地区、时令与预算，一键生成7天个性化饮食计划、采购清单与周食谱
一个自定义技能（Skill）：根据你的生理周期、所在地区、时令食材、当地价格和做饭条件，生成真正买得到、做得完、吃得完的一周饮食方案。

## 功能

- 7 天个性化菜单（以减重/增肌/维持/ 健康调理为目的，支持减重、酮生物/平衡激素两种模式）
- 周期阶段适配（月经期/卵泡期/黄体期 /经前期自动调整安排/无经期女性或男性可选择不适用周期）
- 采购清单：食材、购买量、常见规格、参考价、平替、剩余去向
- 一人食"一锅出"模式，工作日/周末餐次灵活配置
- 食堂外食餐次点餐模板与营养区间估算
- 输出格式：PDF / HTML / Markdown / Word

## 使用

在支持agent的ai输入框输入 `/` 选择"月食"，直接说：

帮我生成下周的周食谱

按提示回答几个问题（年龄、城市、预算、餐次安排等），即可生成属于你自己的一周计划。

## 声明

本技能输出为一般性健康饮食建议，不构成医疗诊断或处方。慢病、孕期、用药等情况请先咨询医生。
