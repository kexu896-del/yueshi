# 月食（yueshi）

**采购驱动的一周饮食计划技能**：先定这周买什么，再决定做什么菜，最后生成一份能照着买的采购清单。

根据人数、周期阶段、健康目标、口味、预算和做饭条件，生成 7 天菜单 + 采购清单（用量、常见规格、参考价、平替、剩余去向）+ 营养校验。菜单来自结构化菜谱库，不是凭空编的菜名。

当前版本：**yueshi-1.4.3**（以 `yueshi/SKILL.md` 为准；变更见 `yueshi/CHANGELOG.md`）

## 能力

- **采购驱动**：食材篮子 → 菜谱检索 → 菜单装配 → 采购反向汇总，全链路闭环；
- **周期与模式**：平衡激素 / 酮生物两种饮食模式，按周期阶段自动排布；涉及断食与低碳水时先做安全筛查；
- **家庭模式**：同餐同量 / 同餐不同量 / 安全分餐，最多两轮全局营养微调，缺席成员只合并局部修改；
- **体质食养（可选）**：仅在你明确自述时启用食材与菜谱的软偏置，覆盖 11 种体质；不输出体质判定、辨证或疗效，不改变安全与预算约束；
- **价格两条路**：叮咚实时页面价（可选助手）或公开参考价估算；
- **四种输出**：PDF / 网页 / Markdown / Word 单选；
- **工程质量**：纯 Python 标准库（无需 pip 安装），回归测试 81 项全绿。

## 仓库结构

- `yueshi/` — 技能本体，入口是 `yueshi/SKILL.md`
- `yueshi-dingdong-helper/` — 叮咚查价助手源码（可选，Windows；不选叮咚查价时完全不需要）
- `kimi.plugin.json` — Kimi Code CLI 插件清单

## 安装

### 方式一：Kimi 插件（推荐）

在 Kimi Code CLI 中执行：

```text
/plugins install https://github.com/kexu896-del/yueshi
```

然后 `/reload` 或开新会话，说"帮我做一周食谱"即可。

### 方式二：手动安装

```bash
git clone https://github.com/kexu896-del/yueshi.git
```

把 `yueshi/` 整个文件夹复制到技能目录：

- Windows：`C:\Users\<你的用户名>\.kimi-code\skills\`
- macOS / Linux：`~/.kimi-code/skills/`

新开会话后，说"帮我做一周食谱"触发。技能只依赖 Python 3.10+ 标准库；PDF 渲染额外调用本机 Chrome/Edge。

### 方式三：不安装，直接当附件

把 `yueshi/` 打包成 zip 发给 AI（或任何能读文件的 AI），让它读取 `SKILL.md` 并按流程执行。

## 使用过程

1. **描述实际情况**：人数、餐次、口味、预算、做饭条件和要避开的食物；缺的信息会合并询问；
2. **删除不想要的食材**：回复不要的编号，都可以就回"都可以"；
3. **月食排菜单并校验营养**：通常不需要额外操作；
4. **选了叮咚查价就查一次**：用助手读取清单，完成后把价格结果上传回对话；
5. **拿最终计划**：7 天菜单、做法、采购清单、预算和剩余食材安排。

## 价格方式（每次计划选一次）

**A. 叮咚查价助手**：按当前页面商品、包装和价格规划；菜单和采购需求确定后生成查价清单并暂停，回传结果后再出最终文件。

**B. 公开参考价**：不调用助手，按所在地公开价格或同类商品估算；可直接出最终文件。

没有选择时，月食会在食材预选环节询问，不会自行默认。

## 叮咚查价助手（可选）

只有选择"叮咚查价助手"时才需要。源码在 `yueshi-dingdong-helper/`；打包版见仓库 Releases 页面（附件名以发布页为准），或按 `yueshi-dingdong-helper/dev/DEVELOPMENT.md` 从源码运行。

使用方式：拖入查价清单 → 在叮咚网页自行登录并确认收货地址 → 点"开始查询" → 下载结果并上传回对话。

助手只读页面商品与价格：**不加购、不下单、不支付、不领券、不改地址**，不读取也不保存你的具体收货地址。价格是查询时点的页面参考价，实际以叮咚结算页为准。

## 环境要求

- 技能：Python 3.10+（仅标准库）；
- PDF 输出：本机装有 Chrome 或 Edge；
- 助手：Windows + Chrome/Edge（不选叮咚查价时可忽略）。
